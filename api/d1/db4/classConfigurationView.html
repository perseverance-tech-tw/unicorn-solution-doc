Detailed Description

Manages the Configuration UI of the application.

The ConfigurationView class inherits from BaseView and handles the initialization, event binding, and state management of the configuration screen. It provides controls for:

  • Selecting different function views (Anypoint 1-4, Panorama).
  • Adjusting parameters such as Alpha, Beta, Zoom.
  • Toggling Flip modes (Horizontal/Vertical).
  • Setting crop margins.
  • Resetting parameters to defaults.

This class uses GTK widgets loaded from a builder and connects signals to specific callback functions.
