Detailed Description

Defines the canonical string identifiers for all View/Camera modes.

These strings are used as keys in the FrameModel and RegionModel to store and retrieve associated data (like processed images or ROI coordinates).

Strict Convention:

  • FN_*: Functional/Algorithm names (Generic).
  • LV_*: Live View specific states.
  • CFG_*: Configuration screen states.
  • FS_*: Full Screen states.
  • MOIS_*: Moving Off Information System states.
  • BSIS_*: Blind Spot Information System states (Right/Left/Reverse).
