Detailed Description

Logic Core for Blind Spot Information System (BSIS) and Moving Off Information System (MOIS).

This namespace implements the business logic for analyzing safety risks around the vehicle. It takes raw object detections (from YOLO), checks them against calibrated Regions of Interest (ROIs), and assigns risk levels (Low/Med/High) based on proximity and zoning rules.

Standards Compliance: The zoning logic is designed to align with UN-ECE R151 (BSIS) and R159 (MOIS) standards for vulnerable road user protection.
