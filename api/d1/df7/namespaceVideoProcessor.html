Detailed Description

The "Director" of the Rendering Pipeline.

This namespace orchestrates the High-Level Application Logic for frame handling. It serves as the bridge between:

  • Inputs: Camera feeds (GStreamer/OpenCV) or Video Files.
  • Logic: AI Detection (VRU/YOLO), Zone Policy Checking.
  • Outputs: Construction of FunctionProcess jobs for the FrameProcessor to render.

Core Loop: The dispatchCurrentViewJobs function is the heartbeat of this module, called every frame to decide what to draw based on the current state (Live/Playback/Config).

◆ dispatchCurrentViewJobs()

void VideoProcessor::dispatchCurrentViewJobs ( )

The main dispatcher function that orchestrates frame processing.

The Primary Frame Orchestrator.

Optimized with:

  1. Fast-Path Logic: Bypasses heavy preprocessing when AI is OFF.
  2. Lookup Cache: O(1) retrieval of Frame/Function records.

  3. Memory Reuse: Static job vector to prevent heap fragmentation.

    This function is the "Brain" of the display loop.

Workflow:

  1. Check State: Are we in Live View? Settings? Playback?
  2. Acquire Frame: Get the latest image from FrameProcessor.
  3. AI Logic: If enabled, schedule or retrieve async AI inference results.
  4. Compose Jobs: Create a list of FunctionProcess tasks (e.g., "Render Main View", "Render Top-Right Mirror").
  5. Dispatch: Send jobs to FrameProcessor::processMultipleTasksAsync.
