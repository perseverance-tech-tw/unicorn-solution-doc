Detailed Description

controls the Global System Settings and Preferences.

The SettingController manages the configuration of hardware and software preferences. It provides the logic for the "Settings" screen, where administrators can configure:

  • Camera Parameters: Intrinsic calibration values (Cx, Cy, Fx, Fy) for the connected cameras.
  • System Clock: Date and Time settings for the embedded system.
  • Resolution: Output display resolution preferences.
  • Localization: Language selection (e.g., English, Indonesian).

This controller interacts directly with the sqlite3 database to persist these settings.
