Detailed Description

Active Record Model for Detection Zones (ROIs).

This model manages the "Regions of Interest" used by the AI detection system. It defines rectangular zones within a camera view where specific rules apply (e.g., "Front Danger Zone").

Concept:

  • ROI: A persistent rectangle (x1, y1, x2, y2) saved in the database.
  • Calibration: Used by the Settings controller to let users draw/adjust detection boundaries.
