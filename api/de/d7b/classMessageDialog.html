Detailed Description

Static factory for displaying Modal System Dialogs.

This wrapper abstracts the GTK GtkDialog API, providing a simple one-line interface for creating standard "Ok" or "Yes/No" popups.

Design:

  • Modal: Blocks interaction with the parent window until dismissed.
  • Themed: Automatically selects icons (Info, Warning, Error) based on MessageType.
  • Thread Safety: Must be called from the main UI thread.
