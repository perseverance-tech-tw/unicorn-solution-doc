Detailed Description

Manages a collection of RegionRecord objects.

This class provides an interface to create, read, update, and delete region configurations. It also handles loading from and saving data to a SQLite database. It inherits from BaseModel to provide generic CRUD functionality.

void RegionModel::loadFromDatabase ( )

Loads region records from a SQLite database into memory.

It finds the first available database from Constants::DB_PATHS, clears the current in-memory records, and populates the model with data from the 'regions' table. If no database is found or is empty, it calls seeder().

◆ saveToDatabase()

void RegionModel::saveToDatabase ( )

Saves all in-memory region records to the SQLite database(s).

This method iterates through all managed RegionRecord objects and persists them to the database paths defined in Constants::DB_PATHS. It will overwrite any existing data in the 'regions' table.
