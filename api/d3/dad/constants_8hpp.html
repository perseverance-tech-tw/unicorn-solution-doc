Detailed Description

Central repository for global configuration, hardcoded paths, and system-wide constants.

This file defines the Constants namespace, which acts as the single source of truth for:

  • File Paths: Locations of databases, YOLO models (weights, configs, names), and assets. Handles differences between Development (local) and Production (installed) environments.
  • Model Identifiers: String constants used to identify specific camera views (e.g., "Panorama", "Anypoint 1"). These are critical for linking the UI dropdowns/buttons with the underlying FrameModel logic.
  • UI Layouts: Hardcoded pixel dimensions for various view modes (Live View, Split Screen, etc.).
  • calibration Defaults: Default parameters (alpha, beta, zoom) for the Moildev engine.
