Detailed Description

Active Record Model for Display Frame Layouts.

This model manages the "Layout Configuration" of the application, determining which camera processing function is assigned to each visual slot on the screen (e.g., "Main View", "Top-Right View").

Domain Logic:

  • Frame: A rectangular area on the application's UI.
  • Function: The image processing logic (e.g., "Panorama", "Rear View") mapped to that area.
  • Persistence: States are saved in SQLite to restore the user's custom layout on reboot.
