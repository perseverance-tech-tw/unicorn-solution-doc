Detailed Description

Implementation of the Logger namespace.

Contains all the private logic, including file I/O, thread-safety, and formatting.

Logs to console and a single date-stamped file in 'logs/'. (e.g., 'logs/app_log_YYYY-MM-DD.log').

Requires C++17 for <filesystem> and links against -lstdc++fs and -lpthread.
