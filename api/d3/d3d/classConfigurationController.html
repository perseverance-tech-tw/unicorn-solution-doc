Detailed Description

Manages the Calibration and Configuration UI for Fisheye Camera Views.

The ConfigurationController handles the complex logic of calibrating the virtual views (Anypoint 1-4, Panorama). It acts as the bridge between the user's calibration inputs (via ConfigurationView) and the persistence layer (FunctionModel/Database).

Key Responsibilities:

  • View Switching: Toggles the main display between different Anypoint views and the Panorama view.
  • Parameter Tuning: Handles live updates of Alpha, Beta, and Zoom parameters from the UI sliders or drag gestures.
  • ROI (Region of Interest) Management: Updates crop margins and flip states.
  • Mode Handling: Switches context between MOIS (Moving Off Information System) and BSIS (Blind Spot Information System) calibration modes.
  • Persistence: Saves the tuned parameters back to the database so they persist across reboots.
