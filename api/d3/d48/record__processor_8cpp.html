Detailed Description

Improved version of the RecordProcessor.

Implementation of the RecordProcessor namespace.

Handles video recording functionality, including file management, disk space monitoring, and adaptive file rotation (5-minute chunks). It ensures that the recording process does not consume all available disk space by automatically deleting old files when space is low.
