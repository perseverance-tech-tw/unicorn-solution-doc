Detailed Description

Active Record Model for Image Processing "Functions" (Presets).

A "Function" in this domain represents a set of optical parameters used to transform a raw fisheye image into a specific view (e.g., "Panorama", "Bird's Eye").

Responsibilities:

  • Parameter Management: Stores Alpha/Beta/Zoom, Shifts, and Margins.
  • Map Caching: Manages the serialization (.xml/.yml) and deserialization of heavy cv::Mat lookup tables (MapX/MapY) to avoid expensive re-computation on every frame.
  • Persistence: Syncs presets with the SQLite functions table.
