Detailed Description

Static Utility for Cross-Platform Hardware Discovery.

CameraProcessor handles the low-level details of interrogating the operating system (Linux V4L2, Windows DirectShow, MacOS AVFoundation) to find connected video sources.

Capabilities:

  • Device Enumeration: Lists all video nodes (/dev/videoX).
  • Availability Testing: Physically attempts to open a stream to verify the device is not busy/broken.
  • Name Resolution: Extracts human-readable names (e.g., "Logitech C920") from system files.
