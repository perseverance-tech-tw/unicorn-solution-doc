Detailed Description

Singleton-like Localization (i18n) Engine.

This static utility class manages the application's multi-language support. It loads JSON translation files (e.g., lang/en.json, lang/id.json) and provides helper methods to dynamically update GTK Widgets (Labels, Buttons, Window Titles) at runtime.

Features:

  • Hot-Swapping: Can change language without restarting the app (via applyTranslationsToBuilder).
  • Persistence: Saves user preference to config/language.conf.
  • RTL Support: Handles text direction changes for languages like Arabic (if supported).
