Detailed Description

Data Object representing a UI Viewport Configuration.

Maps a logical screen area (defined by its ID or Name) to a specific Image Processing Function.

Fields:

  • name: Display label (e.g., "Mois Anypoint 2").
  • function_id: Foreign key to FunctionRecord.
  • width/height: (Deprecated/Legacy) intended for dynamic resizing, but currently fixed by layout.
