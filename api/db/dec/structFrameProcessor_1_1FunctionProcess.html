Detailed Description

Unit of Work for the Rendering Pipeline.

Encapsulates all context required to transform one generic frame into one specific view for a specific UI widget.

Lifecycle:

  1. Created in the Main Loop (Producer).
  2. Copied into the ThreadPool queue.
  3. Processed by a Worker Thread (Consumer).
  4. Resulting cv::Mat is pushed to the UI.
