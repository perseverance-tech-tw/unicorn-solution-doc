Detailed Description

template<typename RecordType>
class BaseModel< RecordType >

Generic Data Repository (Active Record Pattern).

A template-based implementation of standard CRUD operations. It serves as an in-memory database for application entities.

Key Features:

  • CRUD: Create, Read, Update, Delete with ID management.
  • Filtering: functional-style querying (filter, filters).
  • Persistence: (Implied) Derived classes often sync this state to/from SQLite or JSON.
Template Parameters
RecordTypeThe struct representing the data entity (e.g., FrameRecord).

This pure virtual method must be implemented by derived classes. It is intended to seed the model with necessary baseline data (e.g., default settings, initial presets) when the application starts or is reset.
