Detailed Description

Thread-Safe Cache for Available Video Devices.

The CameraManager acts as a stateful wrapper around the low-level CameraProcessor. It provides a stable, thread-safe list of cameras to the UI, preventing the need to blocking-probe the hardware every time a dropdown menu is opened.

Key Features:

  • Lazy Initialization: Scans for cameras only when explicitly requested.
  • Caching: Stores the list to provide instant access for UI rendering.
  • Concurrency: Uses std::shared_mutex to allow multiple UI readers while updating safely.

std::vector< std::pair< int, std::string > > CameraManager::getAvailableCameras ( ) const

Retrieves the Cached Camera List.

Retrieves the current list of available cameras.

Acquires a shared lock (Read Lock) to return the currently known devices. This is fast and non-blocking to other readers, making it safe for high-frequency UI polling.

Returns
A vector of {Index, Name} pairs (e.g., {0, "Integrated Webcam"}).

Returns a copy of the camera list to ensure thread safety for the caller. Uses a shared lock to allow concurrent reads.

Returns
A vector of pairs, where each pair contains the camera ID and its name.

void CameraManager::initializeCameras ( )

Idempotent Initializer.

Initializes the camera detection process safely.

Guarantees that the camera list is populated. If called multiple times, subsequent calls are no-ops. This should be called during the Application Startup phase.

Uses std::call_once to ensure that detectInitialCameras is executed exactly once, even if called from multiple threads.

void CameraManager::refreshCameras ( )

Force-Refreshes the Camera Cache.

Refreshes the list of available cameras.

Acquires a unique lock (Write Lock) on the catalog, clears existing data, and re-scans the system for connected devices. Use this when the user clicks "Refresh" in the UI. Warning: This is a blocking operation and may take seconds.

Queries the system for cameras again and updates the internal list in a thread-safe manner using an exclusive lock.
