Detailed Description

Unified Moildev wrapper class with dynamic backend selection.

This class acts as the main entry point for the Moildev library. It abstracts details of the underlying implementation (CPU or OpenCL) and provides a consistent API. It handles backend loading, initialization, and fallback mechanisms.
