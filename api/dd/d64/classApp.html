Detailed Description

The main application class that orchestrates the GTK UI and global state.

The App class is the root of the application. It inherits from BaseView because the main window itself is a view. It is responsible for:

  • initializing the GTK main loop.
  • Managing the top-level persistent UI elements like the sidebar and the main content stack.
  • Handling global navigation events (switching between Live View, Playback, Settings, etc.).
  • Cleaning up resources upon shutdown.

Constructor & Destructor Documentation

◆ App()

App::App ( )

Constructs the App object.

Constructs the main App.

Initializes the main window, loads the sidebar icons, and sets up the main widget stack.

Loads the primary Glade layout and CSS, connects to the AlertManager, initializes the beeper, and triggers the initial camera detection. It then binds all necessary widgets and connects their signals. Finally, it sets up the view routing and loads the initial LiveView.

◆ ~App()

App::~App ( )

Destroys the App object.

Destructor for App.

Performs necessary cleanup of GTK resources and ensures the application shuts down gracefully.

Releases the main GtkBuilder reference. This recursively frees all widgets loaded from the Glade file.

Note
Do not manually unref individual widgets (like 'window' or 'stack') as they are owned by the builder. Doing so will cause GLib-GObject-CRITICAL errors.

void App::run ( )

Starts the application's main execution loop.

Configures and displays the main window, then enters the GTK main loop.

Enters gtk_main(), blocking until the application window is closed.

This function sets window properties (icon, title, size) and calls gtk_widget_show_all(). It then blocks by calling gtk_main() until the application is quit (e.g., via gtk_main_quit()).
