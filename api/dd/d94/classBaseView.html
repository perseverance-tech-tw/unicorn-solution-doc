Detailed Description

Base Abstraction for GTK User Interfaces.

Handles the boilerplate of loading UI layouts (.glade XML) and applying CSS styles. It provides a structured foundation for all View components, exposing hooks for:

  • Binding: Connecting C++ pointers to GTK widgets (viewBinding).
  • Events: Wiring up signal handlers (signalConnect).
  • Theming: Applying CSS classes to widgets dynamically.

virtual void BaseView::signalConnect ( )

Connects GTK signals (events) to their respective handler functions.

This virtual method is intended to be overridden by derived classes. It handles the wiring of clicks, toggles, and other events to the controller logic.

Reimplemented in App, ConfigurationView, LiveViewView, PlaybackView, and SettingView.

Binds UI widgets from the builder to class member variables.

This virtual method is intended to be overridden by derived classes. It is where subclasses should call gtk_builder_get_object to populate their specific button/label pointers.
