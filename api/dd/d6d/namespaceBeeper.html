Detailed Description

High-Level Audio Alert Controller.

The Beeper namespace provides a unified, thread-safe API for generating audible warnings. It abstracts away the low-level system audio commands (detecting paplay vs aplay) and manages the lifecycle of background threads for repetitive beep patterns.

Features:

  • Pattern Management: Supports "Single Burst" (for warnings) and "Continuous Loop" (for critical alarms).
  • Thread Safety: Safe to call from independent detection threads (Front/Right/Rear).
  • Start-up Logic: Lazily initializes audio resources on the first call to prevent startup latency.
  • Priority Handling: Helper functions to resolve conflicting audio requests (e.g., Critical > Warning).

Updates the Audible Alert State for a specific Zone.

This is the primary interface for the detection logic. It transitions the audio state for a given zone (e.g., "front_camera") based on the requested pattern.

Behavior:

  • NONE: Silences the zone. Stops any active loop.
  • BEEP_2_ONCE: Triggers a non-blocking, fire-and-forget double beep (Warning level).
  • BEEP_3_LOOP: Starts a persistent background thread looping a triple-beep pattern (Critical level).
    • Idempotent: If the loop is already running, this call does nothing.
Parameters
keyUnique identifier for the source zone (e.g., "REGION_FRONT").
patThe target beep pattern.
cfgTiming configuration (optional overrides).
