Detailed Description

Manager for Dynamic Map Resolution Scaling.

This subsystem allows the user to lower the internal rendering resolution of the remapping process to save CPU/GPU cycles on lower-end hardware, without affecting the external window size.

Constraint:

  • Map resolutions (High/Med/Low) are computed relative to the Native Calibration Size of the lens.

◆ applyNewResolution()

void ResolutionProcessor::applyNewResolution ( )

Applies the currently selected resolution by regenerating all maps.

Commit: Triggers Global Map Regeneration.

This function triggers the regeneration of all processing maps (mapX, mapY) using the dimensions of the currently set resolutionNow.

The "Heavy Lifting" function.

  1. Iterates through every FunctionRecord in the database.
  2. Calls MoildevApplicator::regenerateAllMapsWithNewResolution.
  3. Blocks until all binary map files on disk are updated to the new size.

◆ initializeResolutions()

void ResolutionProcessor::initializeResolutions ( )

Dynamically calculates and populates the available resolution settings.

Bootstrapper: Calculates Resolution Tiers.

This function should be called once at startup. It retrieves the native map size from MoildevApplicator and calculates Medium and Low resolutions based on predefined scaling factors. It populates the global resolutionSetting map and sets the default to RES_NATIVE.

Called on startup. Queries the MoildevApplicator for the lens's native diameter (e.g., 2000px) and mathematically derives the RES_MEDIUM (e.g., 70% scale) and RES_LOW (e.g., 40% scale) target dimensions.
