Detailed Description

The primary controller for the Live Camera View and Drive Mode interfaces.

This controller acts as the nerve center for the application's main operational mode. It connects the visual elements of the Live View (video feeds, buttons, overlays) with the underlying logic.

Core Responsibilities:

  • Video Pipeline Management: initializes and controls GStreamer pipelines for camera feeds (MOIS and BSIS).
  • Drive Mode Logic: Toggles between "Standby" (configuration/idle) and "Drive" (active monitoring) modes.
  • Recording: Manages the start/stop logic for saving video feeds to disk, including handling "Background Recording" if configured.
  • View Modes: Switches between specific view layouts like Panorama, Bird's Eye View (BSIS), and raw camera feeds.
  • AI Integration: Toggles object detection overlays (Bounding Boxes, warnings) on the live feed.
