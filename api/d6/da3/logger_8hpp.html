Detailed Description

A lightweight, thread-safe logging interface.

The Logger namespace provides a disciplined way to output system status, avoiding raw std::cout usage. It follows a standard severity hierarchy (DEBUG < INFO < WARN < ERROR).

Usage Principles:

  • DEBUG: High-volume tracing (e.g., "Frame processed in 12ms"). Disabled in Production.
  • INFO: High-level lifecycle events (e.g., "Camera initialized", "User switched mode").
  • WARN: Recoverable issues (e.g., "Config file missing, using defaults").
  • ERROR: Critical failures requiring attention (e.g., "Database write failed").

Supports both std::string messages and C-style printf formatting.
