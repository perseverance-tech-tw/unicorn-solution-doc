Detailed Description

Utilities for GTK Builder (Glade) loading and CSS Management.

This header abstracts the boilerplate code required to load UI definitions from .glade (XML) files and apply application-wide styles. It also handles dynamic asset paths, ensuring resources are found regardless of where the binary is executed.

Key Capabilities:

  • Path Resolution: Locates assets relative to the executable path.
  • UI Loading: Robustly initializes GtkBuilder instances with error checking.
  • Dynamic Styling: Applies CSS to widgets dynamically and manages hover/active states for buttons via images.
