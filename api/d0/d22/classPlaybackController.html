Detailed Description

Manages the Video Review interface (Playback Mode).

The PlaybackController allows the user to review recorded footage. It handles the filesystem interactions required to list recorded videos and plays them back using the application's media player.

Key Features:

  • Thumbnail Generation: Asynchronously generates thumbnails for video files to display in the gallery.
  • File Management: Provides Safe Deletion capabilities for recorded media.
  • Media Playback: Orchestrates the playback of selected video files, including Seek, Pause, and Fullscreen toggle.
