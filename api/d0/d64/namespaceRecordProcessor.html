void RecordProcessor::checkAndRotateFile ( )

Checks if the current recording file has exceeded the chunk duration.

If the current recording has been running longer than CHUNK_DURATION_SEC, it stops the current recording and immediately starts a new one to create a seamless series of video files.

◆ ensureDiskSpace()

void RecordProcessor::ensureDiskSpace ( )

Checks available disk space and deletes old recordings if necessary.

If free space falls below a critical threshold (MIN_FREE_DISK_MB), this function deletes the oldest video files until the target free space (TARGET_FREE_DISK_MB) is reached. It ensures the current active recording is not deleted.
