Detailed Description

Header file for the ConfigurationView class.

This file defines the ConfigurationView class, which is responsible for the configuration interface of the application. It handles the user interactions for adjusting camera parameters, managing different views (Anypoint, Panorama), and communicating with the underlying logic to update the display.
