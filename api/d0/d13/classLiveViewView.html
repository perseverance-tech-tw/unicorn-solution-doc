Detailed Description

View for live view functionality, including media loading and display mode switching.

Manages the Main Live View UI of the application.

Provides UI component binding and connects signals to the controller via the Mediator.

The LiveViewView class provides the mechanism to control the main visual feedback of the system. It handles:

  • Displaying live video feeds from multiple cameras.
  • Switching between different display modes (e.g., MOIS, BSIS, Panorama).
  • Overlaying alerts and detection boxes.
  • Managing recording status and playback controls within the live view.
  • Handling fullscreen toggles and ROI editing.
