Detailed Description

Defines the YoloV8Detector class for ONNX-based object detection.

This header file declares the YoloV8Detector class, which provides a complete pipeline for running a YOLOv8 object detection model using the ONNX Runtime. It also defines the DetectionResult structure for returning detection outputs.
