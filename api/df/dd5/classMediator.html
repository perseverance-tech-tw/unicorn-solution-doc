Detailed Description

The Central Hub using the Singleton pattern to manage ownership and communication between MVC components.

The Mediator class is the backbone of the application's architecture. It acts as a central registry and owner of all major components (Views, Models, Controllers, Detectors, and Thread Pools).

Key Design Principles:

  • Ownership: It strictly uses std::unique_ptr to manage the lifecycle of all components, ensuring automatic and safe destruction when the application exits.
  • Access: Provides a global access point (getInstance()) for controllers to communicate with each other or access models, eliminating the need for complex parameter passing.
  • Decoupling: While it couples components to the Mediator, it prevents them from needing direct references to every other component, simplifying the dependency graph.
