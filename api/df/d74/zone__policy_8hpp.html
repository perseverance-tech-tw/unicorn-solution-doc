Detailed Description

Business Rules for mapping Display Views to Risk Zones.

This file defines the Policy Layer that translates abstract View Names (like "Anypoint 1") into concrete physical Safety Zones ("Front", "Right"). It decouples the UI representation from the Safety Logic.

◆ resolvePolicyFor()

ZonePolicy resolvePolicyFor ( const std::string &  frameName)
inline

Resolves the Safety Policy for a given View/Frame Name.

Determines which physical zone a camera view belongs to and what alert features are enabled.

Policy Rules:

  • Panorama: Zone::NONE (Passive view, no active alerting).
  • Anypoint 2: Zone::FRONT (MOIS - Moving Off Information System).
  • Anypoint 1/3/4: Zone::RIGHT (BSIS - Blind Spot Information System).
  • Default: Zone::RIGHT (Conservative fallback).
Parameters
frameNameThe identifier string of the view (case-insensitive).
Returns
ZonePolicy Struct containing the physical zone enum and border permission flag.
